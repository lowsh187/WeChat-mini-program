# 后端安全记录

## AI 密钥

- AI 密钥只能通过云函数环境变量 `AI_API_KEY` 注入。
- `AI_BASE_URL` 必须为 HTTPS，模型名通过 `AI_MODEL` 配置。
- 禁止将真实密钥写入源码、Git、前端、日志、错误响应或测试 fixture。
- 聊天、工单或截图中出现过的真实密钥应视为已暴露，并在部署前轮换。
- Provider 未配置或调用失败时返回降级状态，不使用技术占位 0 分。

## wx-server-sdk 依赖审计

首次记录：2026-10-08；复核日期：2026-10-12

所有已实现云函数使用官方 `wx-server-sdk@4.0.2`。npm 审计报告每个独立云函数依赖树包含 1 个中危、5 个高危传递依赖风险，主要来自 Axios 与 lodash；自动建议降级到 `2.5.3`，但该版本的完整依赖树产生更多漏洞，其中包含严重级别，因此不采用降级方案。

当前缓解措施：

- 使用官方当前版本并精确锁定；
- 固定数据库集合名，不接受客户端传入集合、URL、代理或请求目标；
- 每个函数只提取契约允许的字段；埋点拒绝自由正文，反馈和偏好文本拒绝手机号、邮箱及超长输入；
- 不把任意客户端对象透传给 SDK；
- 不保存原始 OpenID、设备会话 ID 或删除令牌；
- AI Provider 只允许由服务端环境变量配置的 HTTPS 目标；不接受客户端 URL、模型或密钥；
- 生产部署前再次执行 `npm audit --omit=dev` 并复查官方 SDK 更新。

此记录不是忽略漏洞。若官方发布不含上述依赖风险的新版本，应在通过回归测试后升级。
