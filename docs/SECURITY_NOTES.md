# 后端安全记录

## wx-server-sdk 依赖审计

记录日期：2026-10-08

`createSession` 使用官方 `wx-server-sdk@4.0.2`。npm 审计报告其传递依赖包含已知 Axios 与 lodash 风险；自动建议降级到 `2.5.3`，但该版本的完整依赖树产生更多漏洞，其中包含严重级别，因此不采用降级方案。

当前缓解措施：

- 使用官方当前版本并精确锁定；
- 固定数据库集合名，不接受客户端传入集合、URL、代理或请求目标；
- 请求只提取并校验 `clientVersion` 与可选匿名设备会话 ID；
- 不把任意客户端对象透传给 SDK；
- 不保存原始 OpenID、设备会话 ID 或删除令牌；
- 云函数不发起外部 HTTP 请求；
- 生产部署前再次执行 `npm audit --omit=dev` 并复查官方 SDK 更新。

此记录不是忽略漏洞。若官方发布不含上述依赖风险的新版本，应在通过回归测试后升级。
