# PathAI API 契约 v1.0.0

## 1. 冻结状态

- 契约版本：`1.0.0`
- 配置版本：`1.0.0`
- 调用方式：小程序通过 `wx.cloud.callFunction` 调用同名云函数。
- 兼容规则：允许新增可选字段；字段删除、改名、类型或语义变化必须升级契约版本并经成员 A、B 共同确认。
- 权威 TypeScript 定义：`shared/contracts.ts`。

## 2. 统一响应

所有云函数都返回：

```json
{
  "status": "success",
  "contractVersion": "1.0.0",
  "configVersion": "1.0.0",
  "data": {},
  "error": null,
  "aiGenerated": false
}
```

`status` 只能为：

- `success`：正常结果；
- `degraded`：AI 超时或不可用，但提供可展示的模板结果；
- `error`：无法安全继续，`data` 为 `null`。

## 3. 统一错误码

| 错误码                     | 含义                           |       是否通常可重试 |
| -------------------------- | ------------------------------ | -------------------: |
| `INVALID_ARGUMENT`         | 请求参数缺失、类型或长度不合法 |                   否 |
| `SCHEMA_VALIDATION_FAILED` | AI 或内部结果未通过固定 Schema |               视情况 |
| `AI_TIMEOUT`               | AI 调用超过 15 秒              | 是，最多一次安全重试 |
| `AI_UNAVAILABLE`           | AI 服务不可用                  |                   是 |
| `CONTENT_RISK`             | 输入或输出触发内容安全规则     |                   否 |
| `SESSION_EXPIRED`          | 匿名会话不存在或已失效         |       否，需新建会话 |
| `UNKNOWN_ERROR`            | 未分类错误                     |               视情况 |

客户端不得显示内部堆栈、提示词、密钥或供应商原始错误。

## 4. 云函数清单

| 函数                       | 请求                             | 成功数据                              |             AI |
| -------------------------- | -------------------------------- | ------------------------------------- | -------------: |
| `createSession`            | 客户端版本、可选匿名设备会话标记 | `sessionId`、初始进度                 |             否 |
| `selectFollowup`           | 会话、轮次、已答题和维度证据     | 固定题库中的维度、题目 ID 与文本      | 是，仅选择题目 |
| `getInitialRecommendation` | 基础题、偏好和追问答案           | 六维评分、恰好 3 个岗位与依据         |           部分 |
| `scoreTrial`               | 会话、试岗 ID 和回答             | Rubric 评分、证据、推荐前后及变化解释 |             是 |
| `getActionPlan`            | 岗位、能力差距和少量偏好         | 恰好 7 天任务与建议                   |           部分 |
| `submitFeedback`           | 帮助度、感兴趣岗位和可选反馈     | 是否接收                              |             否 |
| `trackEvent`               | 匿名事件、步骤和可选耗时         | 是否接收                              |             否 |
| `deleteSession`            | 会话和删除确认令牌               | 是否删除                              |             否 |

完整字段定义见 `shared/contracts.ts`。

## 5. 固定业务约束

- 六维固定：信息提炼、逻辑分析、用户洞察、表达沟通、执行规划、创意发散。
- 岗位固定：数据分析、产品运营、用户研究、产品经理、项目管理、内容策划。
- 初步推荐分：40% 基础情境题 + 30% 用户偏好 + 30% AI 追问证据。
- 试岗后推荐分：45% 初步推荐分 + 55% 试岗行为表现。
- Rubric 分数只能为 0～5，且 `evidence`、`improvement` 非空。
- 追问最多两轮，只能返回预设题库中的题目 ID。
- AI 调用 15 秒超时；仅允许一次安全重试；失败必须明确降级。
- AI 不得临时创建能力维度、岗位权重或评价标准。

## 6. 隐私与日志

- 使用匿名 `sessionId`，不要求手机号、姓名或实名信息。
- `trackEvent` 禁止携带完整回答、联系方式和敏感画像。
- 日志只记录脱敏的延迟、错误类别、契约版本和 Schema 结果。
- `deleteSession` 必须清理会话关联的画像、评分、计划和反馈记录。
- AI API 密钥只允许保存在云函数安全配置中。
